自 v1.11.0 正式版以来的全部改动汇总（含 1.12.0-alpha 预览版内容）。

- **实验性：同命令列表原地内联执行架构（NrInline 模式）**：
  - 为《红色沙漠》（Crimson Desert）等当前无法进行帧切分的游戏特别修复，待实机测试；内联模式帧数待优化，请尝试内联菜单内多处实验性开关比较使用。
- **Mochizuki 官方 a9b13dd 深度集成与 ACO 编译器支持**：
  - 修复 ACO 解码器尾部（C64 到 fused-C32）屏障依赖与生命周期边界（感谢 @[Overclockers](https://github.com/TheAutomatic/dlss-5-amd-project/commits?author=Overclockers)）。
  - 支持可选 30 层降噪模式与 SR 后 NR 运动矢量直通。
- **《极限竞速：地平线 6》（Forza Horizon 6）兼容**（感谢 B 站 [清明yyyyy](https://space.bilibili.com/651151676) 测试反馈）：
  - 保留录制代理并规范增强屏障输入（感谢 @[Overclockers](https://github.com/TheAutomatic/dlss-5-amd-project/commits?author=Overclockers)，PR #8）。
  - 进程名含 `forza` 时自动开启「早期包装所有模块」（`LmxxfEarlyAnyModuleWrap`，需重启生效）与「允许增强屏障」（`LmxxfAllowEnhancedBarriers`，即时生效），二者均可在菜单强制开/关；地平线不使用内联模式。
- **《最终幻想 VII 重生》画面修复**（感谢 B 站 [清明yyyyy](https://space.bilibili.com/651151676) 测试反馈）：游戏中途切换颜色格式时自动转换，避免画面异常；格式不变的游戏不受影响。
- **Mochizuki 移植本端 lmxxf 模式的曝光与白点**（感谢 @[Ciaranoff](https://github.com/TheAutomatic/dlss-5-amd-project/commits?author=Ciaranoff)，PR #9）：
  - 新增「白点来源」下拉：关闭 / 跟随游戏 / 自行测光 / 自动，默认关闭（INI `MochizukiWhitePointSource`）。
  - 「白点/微调」滑块与之并列显示在 Mochizuki 输入页；选择自动来源时它是在自动结果上的亮度微调，1.0 为不调整。
- **Mochizuki 其他改动**：ACO 快速模式默认开启（已有 INI 中的 `MochizukiAcoMode=false` 不会被迁移）；安装时只提取权重；内联模式支持 FP16 输入，符合条件的内联链在计算队列上运行。
- **菜单**：Mochizuki 预处理开启且为多层模式时，在人物保护处提示其不会生效；隐藏 AMD 后端不使用的 NGX 全局白点设置；标题栏与启动画面显示免费软件声明。
- **审查修复与发布加固**：补入 LICENSE / NOTICE 与 lmxxf MIT 许可；可写 ACO 驱动缓存迁至 `LOCALAPPDATA`；内联中止的完成确认与回收；发布正文改由版本化文件生成。
- 新增若干默认关闭的内联诊断与实验开关（`NrFrameDiag`、`NrGpuHandoff`、`NrInlineReuse`、`NrCaptureBackoff`）。
- **架构稳定性与自动化测试回归**。

**安装与对应后端权重准备**

- 请完整解压 ZIP 至任意文件夹并运行新包的 `Setup.bat`。更新时推荐选择 **Y 先卸载**，重新使用包内默认配置（已自带人物模型保留规则）。
- **Daniel 0.6.0**：运行文件请前往 [Daniel 官方发布页](https://github.com/danielblnc/DLSS-NR-on-AMD/releases) 获取；`nvngx_dlssnr.dll` 310.8.0 请自行获取。
- **lmxxf 0.41**：请从合法持有且许可允许使用的模型文件自行准备 `native-game-tiled-assets` 权重目录，提取方法见 [原仓库](https://github.com/lmxxf/dlss5-on-amd-9070xt-porting)。
- **Mochizuki 0.0.4（引入 0.04/a9b13dd 特性）**：从 `nvngx_dlssnr.dll` 310.8.0（与 Daniel 使用同一文件）提取权重，需要 Python 3.10+。
- 本包已内置 PP-HumanSeg 与 YOLO11n-seg 人物分割模型权重（见 Licenses/）；不含 NVIDIA DLL、Daniel 安装器或全图专有神经渲染权重。

**已知问题**

- 实验性内联模式（`NrInline`）目前需在配置中显式开启，专用于解决不兼容命令列表拆分的游戏；在已兼容切分模式的游戏中建议保持默认。有限自旋预算不保证跨队列进度或帧时间上界。
- SR → NR 支持 DX12 及 DX11/Vulkan 转 DX12 桥接，不扩展原生 RR/Vulkan；不支持的纹理布局保留 SR 图像并显示原因。
- lmxxf 时序历史（抗闪烁）功能与 ViT 自适应复用继续互斥；建议关闭预测第 3 层。
- 部分场景与 XeFG 插件冲突，请关闭 XeFG 后重新进入游戏。

感谢各位用户的测试与反馈。

### v1.12.0-alpha2

Summary of all changes since the v1.11.0 stable release (including the 1.12.0-alpha preview).

- **Experimental: Same-Command-List Inline NR Execution (`NrInline` Mode)**:
  - A dedicated fix for games that currently cannot use frame splitting, such as *Crimson Desert*; pending in-game testing. Inline frame rate still needs optimization; please try the experimental switches in the Inline menu and compare.
- **Mochizuki Official a9b13dd Upstream Integration & ACO Compiler Support**:
  - Fixed ACO decoder-tail (C64 to fused-C32) barrier dependencies and lifetime boundaries (special thanks to @[Overclockers](https://github.com/TheAutomatic/dlss-5-amd-project/commits?author=Overclockers)).
  - Added selectable 30-layer pass mode and post-SR NR motion vector passthrough.
- **Forza Horizon 6 compatibility** (thanks to [清明yyyyy](https://space.bilibili.com/651151676) on Bilibili for testing and feedback):
  - Recording proxies are preserved and enhanced-barrier inputs normalized (thanks to @[Overclockers](https://github.com/TheAutomatic/dlss-5-amd-project/commits?author=Overclockers), PR #8).
  - For executables whose name contains `forza`, early wrap of all modules (`LmxxfEarlyAnyModuleWrap`, restart required) and Allow enhanced barriers (`LmxxfAllowEnhancedBarriers`, applies live) turn on automatically; both can be forced on/off in the menu. Forza does not use inline mode.
- **Final Fantasy VII Rebirth image fix** (thanks to [清明yyyyy](https://space.bilibili.com/651151676) on Bilibili for testing and feedback): when the game switches colour format mid-session, NR now converts it automatically to avoid a broken image; games that keep one format are unaffected.
- **Mochizuki now has the lmxxf-mode exposure and white point** (thanks to @[Ciaranoff](https://github.com/TheAutomatic/dlss-5-amd-project/commits?author=Ciaranoff), PR #9):
  - New "White point source" dropdown: Off / Follow game / Own meter / Auto, default Off (INI `MochizukiWhitePointSource`).
  - The "White point / brightness trim" slider now sits next to it on the Mochizuki input page; with an auto source it is a brightness trim on the automatic result, 1.0 = no change.
- **Other Mochizuki changes**: ACO fast mode is on by default (existing INIs with `MochizukiAcoMode=false` are not migrated); installation extracts only the weights; inline mode accepts FP16 input and eligible inline chains run on the compute queue.
- **Menu**: a warning under Person protection when Mochizuki preprocessing is on in multi-pass mode (protection does not apply); NGX-only global white point settings, unused by AMD backends, are hidden; the title bar and splash show a free-software notice.
- **Review fixes and release hardening**: LICENSE / NOTICE and the lmxxf MIT licence are included; the writable ACO driver cache moved to `LOCALAPPDATA`; inline aborts are certified and reclaimed; the release body is generated from a versioned notes file.
- Several default-off inline diagnostics and experimental switches (`NrFrameDiag`, `NrGpuHandoff`, `NrInlineReuse`, `NrCaptureBackoff`).
- **Architectural Stability & Automated Test Coverage**.

**Installation and backend model preparation**

- Extract the complete ZIP into a folder of your choice and run `Setup.bat`. When updating, we recommend choosing **Y to uninstall first** and start with default settings (existing person models are preserved automatically).
- **Daniel 0.6.0**: obtain runtime files from the [Daniel releases page](https://github.com/danielblnc/DLSS-NR-on-AMD/releases). Obtain `nvngx_dlssnr.dll` 310.8.0 separately.
- **lmxxf 0.41**: prepare `native-game-tiled-assets` from model files you lawfully possess and are permitted to use; extraction instructions are in the [upstream repository](https://github.com/lmxxf/dlss5-on-amd-9070xt-porting).
- **Mochizuki 0.0.4 (includes 0.04/a9b13dd features)**: extract weights from `nvngx_dlssnr.dll` 310.8.0 (same file as Daniel). Python 3.10+ is required.
- Bundles PP-HumanSeg and YOLO11n-seg person partition models (see Licenses/); NVIDIA DLLs, Daniel installers, and proprietary neural weights are not included.

**Known issues**

- Experimental `NrInline` mode must be explicitly enabled in configuration; intended specifically for games with split-ineligible command lists. Keep default split mode for normally compatible titles. Bounded spinning does not guarantee cross-queue progress or a frame-time limit.
- SR → NR supports DX12 and DX11/Vulkan-to-DX12 bridges; does not provide native RR/Vulkan. Unsupported layouts retain the SR frame and display diagnostic reasons.
- lmxxf temporal history and adaptive ViT reuse remain mutually exclusive. Disabling predicted pass 3 is recommended.
- May conflict with the XeFG plugin in certain titles; disable XeFG and restart the game if encountered.

Thanks to all users for testing and feedback.

This archive does not include NVIDIA proprietary binaries, the danielblnc installer, or unauthorized model weights.
